Core pattern to extract (not copy blindly):

2. Deterministic render harness → PNGs from known viewpoints
3. Vision-first judge (look at PNGs vs refs; don’t argue from file intent)
4. One small edit per tick
5. Re-render + compare; revert if worse
6. Tick log with gaps / edit / result / next
7. Hard isolation: don’t touch unrelated systems
8. Clear stop conditions (“good enough”, max ticks)
